# Safety

- Patch only images from the exact ROM build intended for the target device.
- Confirm whether the device uses `boot.img` or `init_boot.img` before flashing.
- Keep the original images and a working recovery procedure.
- Never commit personal device dumps, credentials, private keys, or patched boot images.
- Obtain Magisk APKs and binaries from the [official upstream project](https://github.com/topjohnwu/Magisk).
- Review scripts before running them with elevated permissions.
- An apparently successful patch is not proof of device compatibility.

These utilities are provided as-is.
